# TraceFlow — вебсистема трасування вимог до тестів

Практична реалізація лабораторних №6–7: адаптивний фронтенд на **React + Vite** із тестовим REST API (**json-server**).

## Запуск (Windows / PowerShell)

Потрібен Node.js 20+ та npm. Розпакуйте архів і відкрийте термінал у папці `traceability-frontend`.

```powershell
npm install
npm run api
```

Не закриваючи перший термінал, відкрийте другий термінал у цій самій папці:

```powershell
npm run dev
```

У браузері відкрийте **http://localhost:5173**. Тестовий API працює на **http://localhost:3001**.

## Реалізовані можливості
- Головна панель: кількість вимог, тест-кейсів, зв'язків, покриття.
- Каталог вимог: список, пошук, фільтр статусу.
- Додавання, редагування, видалення вимог через `fetch` / REST API.
- Валідація назви (від 3 символів); повідомлення про помилки.
- Перегляд тест-кейсів.
- Матриця трасування: перегляд, створення та видалення зв'язків, захист від дублювання через UI.
- Адаптивний макет Desktop/Mobile, мобільне меню.

## Як робити скриншоти для звіту
1. Відкрийте `http://localhost:5173` на десктопі — зробіть скриншот головної панелі.
2. Перейдіть у «Вимоги», натисніть «Додати вимогу» — скриншот форми.
3. `F12` → Device Toolbar (`Ctrl+Shift+M`) → ширина 390px — скриншот мобільної версії.
4. Перейдіть у «Матриця трасування» — скриншот зв'язків.

## Важливо
Файл `db.json` є **макетною базою**, не PostgreSQL. Дані з `db.json` ізольовані від створеної в лабораторній №5 бази `traceability_db`. У наступній лабораторній REST-запити `/api/*` будуть підключені до реального Django backend, а бекенд — до PostgreSQL. `users` / ролі поки не авторизуються: аватар AD є демонстраційним.

`npm run build` — збірка production-версії.

## Обмеження прототипу
- CRUD реалізований для вимог; для тестів — перегляд; для зв'язків — створення/видалення.
- Немає реальної авторизації, серверної перевірки дублювання, історії змін, імпорту/експорту; усе це завдання майбутніх етапів.
- Локальний `json-server` потрібен для демонстрації, не використовуйте його як production API.
